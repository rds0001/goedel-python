# Sources and dependencies

The core runtime uses the Python standard library only. Optional NetworkX graph
exports use NetworkX under its own BSD license; NetworkX is not bundled. Mathematical explanations and
examples are independently written. The catalogue contains bibliographic citations
and precise locators for the mathematical literature; no source-book extracts or
third-party formal proof code are distributed. Development tools retain their
respective licenses and are not bundled with the package.

Arithmetic representation resources are generated from this project's explicit
register programs and compiler. Their source hashes and mathematical review records
are included for provenance. A reported external formalization is not a claim that
its proof assistant has been replayed by this package.
