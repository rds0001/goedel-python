# Changelog

## 0.2.0 (local candidate)

Adds native arithmetic theory objects and induction, finite first-order and modal
semantics, scoped natural deduction with equality and discharge, exact numerical
sequence and arithmetic DAG coding, DAG proof replay, concrete conditional fixed
points, register execution and trace checks, and reviewed typed catalogue inference.
Original small-expression syntax and byte numbering remain compatible.

## 0.1.0

Initial native Python release candidate: finite first-order syntax, capture-avoiding
substitution, exact decimal Goedel codes, explicit proof checking, bounded search,
versioned literature catalogue, conditional applicability and Python/R reference cases.
